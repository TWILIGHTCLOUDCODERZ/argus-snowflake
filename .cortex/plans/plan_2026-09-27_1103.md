### Step 2 — Create `ARGUS.GOVERNED.FN_GROUNDING_CHECK` (JavaScript UDF)
```
FN_GROUNDING_CHECK(P_NARRATIVE STRING, P_CITED_CLAIM_TEXTS STRING) → VARIANT
```
Logic:
1. Strip ignorable patterns from narrative copy: `A\d{7}`, `TX\d{8,}`, `FND-\d+`, `TYP-\d+`, `OB-\d+`, `CL-\d+`, `\[C\d+\]`, `STR-\d{4}-\d+`, `Art.\s*\d+(\.\d+)?`, `FC-\d+(\.\d+)?`, `Section\s+\d+(\.\d+)?`, dates `\d{4}-\d{2}-\d{2}(\s+\d{2}:\d{2})?`, standalone years `20[2-3]\d`
2. Extract remaining numbers (including comma-formatted decimals)
3. Normalize: strip commas, parse as float, deduplicate
4. For each number, check if it appears (numerically) in normalized cited claim texts
5. Return `{numbers_checked: N, violations: [...], passed: BOOL}`
